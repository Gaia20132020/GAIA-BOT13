# Gaia's Discord Bot

Bot Discord in Python con prefisso `!`.

## Requisiti
- Python 3.11+
- FFmpeg installato
- MongoDB (locale o Atlas)
- Intents attivi: Message Content, Server Members

## Setup
pip install -r requirements.txt
python main.py

## Deploy 24/7
Railway/Render/Fly.io, start command: `python bot/main.py`
